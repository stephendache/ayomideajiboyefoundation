# Ayomide Ajiboye Foundation Website
Static, mobile-first website for the Ayomide Ajiboye Foundation (AAF).
---

## Stack
* HTML, CSS, JavaScript

---
## Run
```bash
git clone https://github.com/stephendache/ayomideajiboyefoundation.git
cd ayomideajiboyefoundation
open index.html
```

## Deploy
GitHub Pages / Netlify / Vercel

## Notes
* Mobile-first Application
* SEO (meta, schema, sitemap)

## Tradeoffs
The site is intentionally implemented as a static frontend to reduce hosting complexity, eliminate build dependencies, and simplify long-term maintenance for anyone.
